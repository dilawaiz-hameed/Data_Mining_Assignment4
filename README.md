##  Running the Notebook

1. Open `DS3002_Assignment4.ipynb` in Jupyter or Google Colab
2. Run all cells **in order** from top to bottom
3. The final **Save Models** cell generates `model_xgb.pkl` and `feature_names.pkl`

>  **Important cell order:** Run Part C (ablation study) **before** Part D (CNN). The `keras.backend.clear_session()` call at the top of the C3 ablation cell must execute before the CNN is built in D2 — otherwise D3 (feature map visualisation) will fail with an `AttributeError`.

---

##  Running the Dashboard (Part E)

1. Run the notebook first to generate `model_xgb.pkl` and `feature_names.pkl`
2. Place `app.py`, `model_xgb.pkl`, and `feature_names.pkl` in the same folder
3. Launch:

```bash
streamlit run app.py
```

4. Open **http://localhost:8501** in your browser

##  Dashboard Features

- 13-feature patient input form (pre-populated with a real test patient)
- Colour-coded prediction result — 🟢 No Disease / 🔴 Disease Present
- Confidence percentage from XGBoost `predict_proba`
- SHAP bar chart showing the top 3 features driving each prediction
- Auto-generated plain-English clinical explanation for non-technical staff
- Preprocessor rebuilt on-the-fly to avoid sklearn version mismatches

##  Notes

- `SEED = 42` used throughout for full reproducibility
- The preprocessor is rebuilt from raw data in `app.py` to avoid sklearn version mismatches between the training environment and local machine
- All plots are saved as `.png` files in the working directory during notebook execution
- `class_weight='balanced'` used instead of SMOTE — class ratio is 0.91, well above the 0.7 imbalance threshold
